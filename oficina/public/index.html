Como funciona

    
O mesmo raciocínio da palestra — agora com servidor

    
A diferença entre o simulador e a oficina: aqui o evento sai do seu navegador como uma requisição HTTP, é processado por um servidor Node no Render, e a decisão volta para a tela. Nada é encenado no front.

    

      
1 · Webhook
Um endereço só seu. Quem fizer POST nele entrega um evento ao seu robô.

      
2 · Regras
O servidor lê suas regras e decide o caminho. Mudou a regra, muda a decisão dos próximos eventos.

      
3 · Ação
Alerta na tela e, se você configurar, um POST real para o webhook.site.

      
4 · Registro
Cada execução fica no histórico. O placar é calculado a partir dele.

      
O desafio
Ajuste as regras até passar de 80. Depois tente 90+ trocando de cenário.

      
Dica de aula
Cada dupla usa um nome de espaço diferente. O Painel da turma mostra todos os placares.

    

    
O que é real aqui

    
Requisições HTTP, regras no servidor, ação externa, log e placar. O que é de mentira: os eventos do “dia completo”, que são fixos para todos compararem o mesmo cenário.
